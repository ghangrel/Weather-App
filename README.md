# Weather App 

Una aplicación web interactiva que muestra el pronóstico meteorológico en tiempo real utilizando una estética visual inspirada en el anime (Ghibli).

## Características

- Consulta del clima actual mediante código postal.
- Cambio de fondos ilustrados según el estado del tiempo (sol, lluvia, nubes, noche).
- Interfaz adaptativa (responsive) para móviles y escritorio.

## Tecnologías utilizadas

- **HTML5** / **CSS3**
- **JavaScript (ES6+)**
- **APIs:** 
  - [Open-Meteo API](https://open-meteo.com/) (Datos meteorológicos)
  - [Zippopotam.us](https://www.zippopotam.us/) (Geocodificación por código postal)

## Uso

- La idea principal es que quede como web app, para usar directamente desde mi web.
